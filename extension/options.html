Küçük Punto

Kullanım koşulları, gizlilik politikası ve abonelik şartları için kanıta dayalı risk raporu

Hukuki tavsiye değildir. Küçük Punto otomatik bir okuma yardımıdır; hata yapabilir ve sözleşmenin yerine geçmez.

Model sağlayıcısı

Kendi API anahtarınızı kullanırsınız. Küçük Punto'nun bir sunucusu yoktur; metin doğrudan tarayıcınızdan seçtiğiniz sağlayıcıya gider.

Gelişmiş: model adı ve adres

Boş bırakılırsa sağlayıcının varsayılanı kullanılır.

Neler gönderilir, neler gönderilmez?

  • Analize bastığınızda yalnızca ekranda görünen metin sağlayıcıya gönderilir. Gizlenmiş metinler (CSS ile saklanmış, beyaz üstüne beyaz, mikroskobik yazı, ekran dışı) gönderilmez; size ayrıca raporlanır.
  • API anahtarınız bu tarayıcının eklenti deposunda (chrome.storage.local) durur, senkronize edilmez ve yalnızca seçtiğiniz sağlayıcının adresine gider. Sayfaların ona erişimi yoktur.
  • Model sayfada hiçbir şey yapamaz: tıklama, yazma veya kod çalıştırma yetkisi yoktur. Yalnızca JSON döndürür; JSON şemaya ve alıntı doğrulamasına girer.
  • Risk skorunu model değil, eklentinin kendi kodu hesaplar.
